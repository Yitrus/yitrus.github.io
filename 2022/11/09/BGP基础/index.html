自治域AS

是一个有权自主地决定在本系统中应采用各种路由协议的小型单位。它是一个单独的可管理的网络单元（例如一所大学，一个企业或者一个公司个体）。一个自治系统有时也被称为是一个路由选择域（routing domain）。

#添加到自治域100，和取消自治域
router bgp 100
no router bgp

路由器的4种配置模式

  1. 用户模式：路由器名称为ciscoP，则提示符为"ciscoP>"。在这一级别，用户只能查看路由器的一些基本状态，不能进行设置。
  2. 特权模式：特权模式的**系统提示符是”#”**，在这一级别上，用户可以使用show和debug命令进行配置检查。如果要修改路由器配置，还必须进入第3级。如果路由器为ciscoP，则提示如下：
    CiscoP>enable #简写为en
Password:……
CiscoP#e
  3. 配置模式：修改路由器的配置，比如配置路由器的静态路由表。如果想配置具体端口，还需要进入第4级。在特权模式中输入**命令”config terminal”（configuration），简写“con”则相应提示符为”(config)#”**。如下所示：
    CiscoP#config terminal
CiscoP(config)#
  4. 端口配置模式:比如，现在想对以太网端口0进行配置，需要使用命令”interface ethernet0”，如下所示:
CiscoP(config)#interface ethernet0
CiscoP(config-int)#

BGP show命令的一些解释

路由表：show ip bgp

①BGP table version is 2 为BGP表的版本为2，版本号代表这个表变化了几次
②local router ID is 3.3.3.3 为该BGP的RID为3.3.3.3
③* 为这条路由有资格加入路由表，一般只有最优路由才有资格加入
④s suppressed 为被抑制路由，它不能被加表也无法传递
⑤r RIB-failure 为路由信息库的失败，一般是由管理距离引起的（就是你通过 BGP与IGP学到了一条相同路由但后者的管理距离比你小，导致你在加表时加的 是IGP路由），这种路由虽不能加表但可以传递给其他邻居
⑥> 代表为最优路由，BGP表中一般星号加>号这种路由比较常见
⑦

这个黄颜色的空格表示这是一个EBGP路由，只要是本地产生的或是EBGP邻居传递的这条路由前面都打空格，而如果是通过IBGP学习到的路由则为i
⑧Network：3.3.3.0/24 为BGP路由的前缀与掩码，如果遇到只有前缀没有掩码的则代表这条路由为主类路由
⑨ Next Hop：0.0.0.0 为BGP路由的下一跳
⑩Metric 在BGP中代表MED，BGP中根本就没有Metric这一说，只是思科这么叫
⑪ LocPrf 为本地优先级
⑫ Weight 为权重
⑬ Path 为AS-path，本地始发路由AS-path为0，如果是传给IBGP则AS-path不变，只有传给EBGP时AS-path才会改变 ，AS-path的添加是从右往左的，从左往右是数据层面
⑭

这个i表示的不是IBGP而是Origin起源属性中的一种，i代表此BGP路由是通过network与Aggregate方式加入到BGP路由表中的，e代表此BGP路由是通过将EGP路由重分发方式加入到BGP路由表中的（在早期时你在思科的设备上既能运行EGP还能运行BGP，而如今其被淘汰）， ？ 代表此BGP路由是通过将IGP路由重分发方式加入到BGP路由表中的

邻居表：show ip bgp summary


①Neighbor 13.1.1.3 表示邻居地址为13.1.1.3
②V 4 表示BGP的版本为4
③AS 3 表示对方在AS3
④MsgSent 5 MsgRcvd 6 表示我向你发送了5个报文，通过你接收到了6个报文
⑤Tblver 2 表示BGP的版本为2
⑥State/PfxRcd 1 这个为数字一语双关，表示我们之间的邻居关系正常与我通过这台邻居收到了几条路由

Loopback接口

Loopback是路由器里面一个完全以软件指定的逻辑上的一个端口（虚接口），它最大的特点就是可以支持所有的平台逻辑接口。能够实现数据交换功能，但是物理上不存在、需要通过配置建立的接口。Loopback接口一旦被创建，其物理状态和链路协议状态永远是Up，即使该接口上没有配置IP地址。正是因为这些特性Loopback 接口具有特殊的用途。

ipv4与ipv6

IPv4地址以点分十进制表示。每个部分代表一组构成8位地址方案的8位地址。IPv6地址使用以冒号分隔的十六进制数字。它分为八个16位块，构成一个128位地址方案。IPv4具有三种不同类型的地址：多播，广播和单播。IPv6还具有三种不同类型的地址：任意广播，单播和多播。
